# Day 08: Video Submission Hub (Publication Side)

## 🎯 Day Objective
Build the video URL submission form and tracking screens for Publication users submitting external media (YouTube, Instagram, Facebook).

---

## 📋 Task Checklist & Deliverables

- [ ] **Upload Video Form Screen**: Fields for Video URL, Channel Name, Category, Tags, and Keywords.
- [ ] **URL Regex Validation**: Validate YouTube/Instagram/Facebook link formats.
- [ ] **My Submissions Screen**: Tabbed view showing submitted videos under `Active` and `Inactive`/`Pending` status.
- [ ] **Moderation Status Badges**: Display submission status tags (`Pending Approval`, `Approved`, `Rejected`).

---

## 🔍 Verification Criteria
- Invalid video URLs show instant validation error feedback.
- Submissions populate cleanly in the `My Submissions` tab with correct initial `Pending` status.
