# Day 07: Test Paper Generator (Publication)

## 🎯 Day Objective
Build the Test Paper Generator module for creating model test papers and answer key sheets based on preset blueprint patterns.

---

## 📋 Task Checklist & Deliverables

- [ ] **Test Blueprint Picker**: Select exam duration, section layout (MCQ, Short, Long), and answer key inclusion toggle.
- [ ] **Model Test Compiler UI**: Display generated test paper preview.
- [ ] **Answer Sheet Tab**: Optional toggle for solution & marking scheme sheet.
- [ ] **PDF Export**: Download and save test paper package to local storage.

---

## 🔍 Verification Criteria
- Test paper and optional answer keys export cleanly as styled PDF documents.
