# Day 06: Question Paper Generator (Publication)

## 🎯 Day Objective
Build the Question Paper Generator flow (`Series -> Class -> Subject`), allowing users to configure question paper parameters and generate exportable PDF outputs.

---

## 📋 Task Checklist & Deliverables

- [ ] **Configuration Form**: Select Series, Class, Subject, Chapter distribution, Difficulty levels (Easy/Medium/Hard), and Total Marks.
- [ ] **Paper Generator Service**: Interface with backend paper compilation API.
- [ ] **PDF Preview Screen**: Render generated question paper with custom Publication header watermark.
- [ ] **Download & Print Hook**: Save PDF locally and trigger device print manager intent.

---

## 🔍 Verification Criteria
- Generated PDF matches selected criteria and displays publication branding header cleanly.
